## 製品概要
### 背景(製品開発のきっかけ、課題等）
大学の数学・物理の学習において、最も重要なのは「どの変形を、どの前提で行ったか」という論理的な思考プロセスを自分の頭で追うことです。
しかし現在、多くの学生が ChatGPT 等の生成AIに数式を質問しています。既存の一般的なAIは、すぐに正解を出力してしまったり、学生が手書きした係数・符号・添字の誤りを「気を利かせて黙って正解に直してしまう」ことがあります。
その結果、学生は「自分がどこで、なぜ間違えたのか」に気づけず、AIの答えを書き写すだけの**「思考のブラックボックス化（思考停止）」**が教育現場で深刻な問題となっています。

### 製品説明（具体的な製品の説明）
**Math Notebook** は、タブレット上で手書きした途中式をそのまま読み取り、数式処理システム（CAS）が論理的整合性を厳密に判定し、**誤りがあれば「答えを教えず、自力で修正するための復帰ループ」を一続きで支援する次世代の学習支援AIノート** です。
演習プリントの PDF をそのまま読み込んで導出をスタートでき、誤りに対しては「前提を満たす反例」と「段階的ヒント」を提示。さらに CAS 事前検証つきの AI 数式補完、筆跡と判定を瞬時に行き来できる多段 Undo/Redo、思考プロセスをレポート用にそのまま書き出せる LaTeX（`.tex`）出力までを一気通貫で提供します。

### 特長
#### 1. 誤りを勝手に直さない「非補正認識」と CAS による厳密な多値判定
一般的なAI学習支援と異なり、マルチモーダルAIが学生の手書き式を**係数抜け・符号ミス・欠落を含めて「書かれたとおり」** に読み取ります。正誤の判定は LLM の曖昧な推論に頼らず、Python の数式処理エンジン（SymPy）が代数・解集合比較で 100% 決定論的に判定（`ok` / `wrong` / `unknown` / `none`）。判定不能な難関積分も断定せず正直に表示し、後続の変形への影響（未検証祖先）を正確に伝播させます。

#### 2. 「前提を満たす反例」と「答えを隠した段階的ヒント」による自力復帰ループ
式が間違っている場合、いきなり正解を表示して終わることは絶対にしません。問題の前提条件（$L>0, n \in \mathbb{Z}_{>0}$ 等）を満たす**「具体的な反例数値（例: $x=1/2$ を代入すると導かれる値は $\sqrt{2}$ ですが、あなたの式は $1$ になります）」**を提示。続けて「ヒント1（観点）」➔「ヒント2（位置）」をアコーディオン形式で段階的に開示し、学生が自力で気づいて書き直すための思考をガイドします。過去の誤り行は修正履歴として薄くノートに残り、学びの軌跡を可視化します。

#### 3. 思考を加速する「CAS検証付きAI補完」＆「状態保持LaTeX出力」
計算に行き詰まった際は、直近の文脈から「`=` 記号の右辺補完」や「次の一手提案」を AI が破線プレビューで提案。この候補も CAS が事前に正しさを検証したものだけを提示し、未解決のエラーがある間はカンニング防止のために補完ボタンをロックします。完成したノートは、下書きや修正履歴、検証状態注記（`[✓ 検証済み]`、`[✓ 局所変形は整合]`、`[─ 資料参照]` 等）を保持した美しい **LaTeX（`.tex`）ファイルとしてワンクリックでエクスポート** でき、大学のレポート作成に直結します。

### 解決出来ること
- **AI による「思考の代行」の撲滅:** 答えを教えるのではなく、誤りの原因（反例）と観点ヒントを与えることで、学生が自力で数式を導出する本質的な数学的思考力を養えます。
- **数式変形のつまずき箇所の即時特定:** 演習中、どの行の変形（積分の展開、符号、定数倍）で論理が破綻したのかを即座に自覚できます。
- **レポート作成・指導の効率化:** 途中式の論理がすべて検証された状態で LaTeX に出力されるため、学生のレポート作成時間が半減し、教員も思考プロセスが一目で採点・確認できます。

## 開発技術
### 活用した技術
#### API・データ
* **Google Gemini 2.5 Flash API:** 手書き数式の非補正認識（AI-R）、AI数式補完（AI-S）、演習プリントPDFの構造化文字起こし（AI-P）。自由文を吐かせず、厳格な MathJSON 構造のみを出力するプロンプト設計。
* **JPHACKS 公式検証用量子力学データセット:** 1次元無限に深い井戸型ポテンシャルの波動関数規格化問題（演習PDF、手書きストローク画像、行1〜5'の期待値データ）。

#### フレームワーク・ライブラリ・モジュール
* **フロントエンド:** 
  - Next.js 14 / React 18, TypeScript
  - Tailwind CSS（UIスタイリング）
  - HTML5 Canvas API / Pointer Events API（スタイラスペン筆圧・高DPI描画エンジン）
  - KaTeX / `react-katex`（数式の高速クライアントレンダリング）
  - Lucide React（UIアイコン）
* **バックエンド ＆ 数式処理系（CAS）:**
  - Python 3.12, FastAPI, Uvicorn, Pydantic
  - **SymPy:** 代数式の同値判定（`simplify`）、方程式の解集合比較（`solveset`）、定積分評価、反例探索エンジン
* **インフラ ＆ ホスティング:**
  - **Vercel:** フロントエンドのホスティング ＆ Next.js Route Handlers によるセキュアなバックエンド中継 Gateway
  - **Supabase:** Supabase Auth（Magic Link によるパスワードレス認証）、PostgreSQL（行レベルセキュリティ RLS を用いたノート手動保存）
  - **Docker / Azure VM:** Python バックエンドのコンテナ化実行環境

#### デバイス
* **タブレット端末:** iPad（Safari / Apple Pencil）
* **PC ブラウザ:** Google Chrome

### 独自技術
#### ハッカソンで開発した独自機能・技術
* **1. 前提条件充足・内部点反例探索エンジン（Evidence Search Engine）:**
  単なる代入ではなく、問題の前提条件（実数・正値・整数制約）をクリアしつつ、三角関数の境界値等による偶然の一致（$0=0$）を避けて不一致を炙り出す独自の反例探索アルゴリズム。
* **2. 欠落保持型の非補正認識（Non-corrective Math OCR）プロンプトアーキテクチャ:**
  一般的な OCR が「$A \sin(kx)$」へ勝手に直してしまうところを、学生が書き落とした「$\sin(kx)$」（係数 $A$ 抜け）を寸分違わずそのまま認識させる LLM プロンプト制御。
* **3. ネットワーク再送ゼロの多段 Undo/Redo キャッシュ基盤（`useHistory` Hook）:**
  手書きストロークの1画消去から、行確定・AI採用・復帰書き直しまでを Command パターンで完全管理。確定行の Undo/Redo 往復時に外部 API を 1 回も叩かずに状態を復元する高レスポンス設計。
* **4. 検証メタデータ完全保持・決定論的 LaTeX エクスポータ:**
  LLM を一切介さず、クライアント側で決定論的に文字列をシリアライズ。誤り履歴を `%` コメントとして残しつつ、各行に `[✓ 検証済み]` や `[✓ 局所変形は整合]` などの審査証跡を完全に出力する変換エンジン。
