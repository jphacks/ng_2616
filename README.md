# MathIDE

![MathIDE — 数学のためのIDE](docs/images/banner.png)

学習支援 × Tech: MathIDEは、大学数学の学習を支援する手書きノートアプリです。途中式の検証やAIによる数式補完を通して、自分で考えることと、学習の効率化を両立します。

## 1. 背景と課題

### 開発の経緯

開発メンバーが高専から大学へ編入した際、講義の難解さや課題の多さに驚きました。理系特有の忙しさから、理解を諦めて生成AIに解答を任せてしまうこともありました。

しかし、完成された解答を得ても、問題を解くための理解は得られません。一方で、すべてを自力で解くには時間がかかります。

### ターゲットユーザー

基礎的な大学数学の学習に悩む、多忙な理系学部生。

数学を理解したいという意欲はありながら、講義や課題に追われ、十分な学習時間を確保できない学生を想定しています。

### 解決したい課題

- 時間をかけて解法を理解したい → 理系学生の時間は限られている
- 早く解くために、AIに頼ったり答えを見る → あまり理解できない

**数式の解法の深い理解×計算の過程を効率化 → 効率的な学力向上を目指す**

## 3. MathIDEの紹介

### 製品概要

MathIDEは、手書きによる数学の学習に、途中式の検証・ヒント・補完等を組み込んだ多機能ノートアプリです。

### 学習フロー

![1. ノートに途中式を手書きする → 2. 一行ずつ数学的な正しさを検証する → 3. 誤りがあれば、根拠やヒントをもとに自分で書き直す（再検証へ） → 4. 必要に応じてAIの補完を利用する → 5. 学習した過程をノートとして保存・出力する](docs/images/flow.png)

### 主な機能

- **途中式をその都度検証し、誤りに早く気づける！**
    - 直前の数式を数学ツールで厳密に検証
- **わからない部分は、答えではなく段階的なヒントをもとに考え直せる！**
    - 段階的なヒントで解き方をサポート
- **十分理解できている計算や煩雑な作業は、補完機能で効率化できる！**
    - AIによる数式補完
    - 補完された数式にも検証機能を適用し、正確性を保証

**ただし！** 補完に頼りすぎれば、自分で考える機会を失ってしまいます。そこで、ヒントと補完を必要に応じて使い分け、AIにどこまで頼るかを学生自身が選べる設計としました。補完も自動では確定せず、採用するかどうかは学生が判断します。

- **作成したノートを、レポートとして出力！**
    - 理解に利用したノートを、レポート形式に変換してpdfファイルとして出力

## 4. 既存サービスとの差別化

既存サービスにも、数式の解答生成や途中式の検証、AIによる学習支援などの機能はあります。

MathIDEは、**学生自身が考え、解き進める過程そのものを支援すること**に重点を置いています。

- **解答ではなく、解く過程を中心とした学習体験**
    - 学生が一行ずつ数式を書き進めるノートそのものに学習支援機能を統合しています。
- **AIをどこまで使うか、学生自身が決められる設計**
    - 学生の理解度や目的に応じて支援の度合いを調整できます。学習の主導権は学生自身にあります。
- **数学的な信頼性とAIによる柔軟な支援の両立**
    - 数学ツールによる検証を組み合わせることで、AIの柔軟性を活かしながら誤りのリスクを抑えています。
- **AIへの依存度を振り返れる**
    - 学生自身が書いた式とAIが補完した式を区別して記録し、どこまで自分の力で解けたかを振り返ることができます。
- 論理的な証明問題の検証
    - 学生が書いた証明をAIがLEAN形式に変換し、論理のつながりや証明の成立を検証します。

MathIDEは、これらを一つのノートに統合することで、**AIによる学習の効率化と、学生が自分で考える機会の確保を両立する学習環境**を実現しています。

### 学習の振り返り

ホーム画面では、これまでの学習をまとめて振り返ることができます。

![あなたの学習: 分野（分野・専門分野・トピック）、書いた行（自分で・アシスト付きの内訳、右辺の補完・次の一手の提案の回数）、活動（日ごとの記入量、連続日数・活動日数）](docs/images/progress.png)

自分で書いた行とAIの補完を利用した行を分けて示すことで、AIにどこまで頼っているかを学生自身が把握できます。

## 5. 実用化の可能性

### 想定する利用シーン

大学の講義・演習・課題など、学生が日常的に数学の問題へ取り組む場面を想定しています。

既存のノートを書く習慣を大きく変えずに利用できることを重視しています。

### サービスとしての発展性

- 理系学部で広く学ばれる基礎数学を対象としている
- Webアプリとして提供でき、専用ハードウェアを必要としない
- 将来的には、対応する数学分野や対象ユーザーの拡大を目指す
