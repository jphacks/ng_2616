# ADR 0007: LuaLaTeXによる課題レポート出力

## 決定

ユーザー指定の `homework_example.tex` の体裁を、外部画像や独自マクロに依存しない固定テンプレートとして実装する。授業名・所属・氏名・学籍番号・日付・レポート名・設問番号・用紙サイズを入力し、ノートの前提と導出を本文に配置する。サンプルの著者名や解答は転用しない。

既定の出力はAzure VM上の専用LuaLaTeXコンパイラーで生成するPDFとする。ブラウザによる簡易PDFは明示的に選べる別方式として残す。この決定はADR 0005のブラウザPDFに関する出力方式の決定を更新する。

## データと経路

ブラウザ → 同一オリジン `POST /api/v1/reports/pdf` → Azure `POST /api/v1/reports/compile` → PDF。

Web APIは認証後、構造化したノートと設定を検証する。数式はIRから再生成し、文章はTeX特殊文字をエスケープする。クライアントから任意のTeXソースやコンパイラーURLは受け取らない。サーバー側で固定テンプレートを組み立て、専用APIキーと検証済みユーザーIDを付けて送信する。APIキーはブラウザへ渡さない。

未保存内容を含む操作開始時点のスナップショットを使用する。原本とUndo/Redo履歴を変更しない。検証状況・出典・修正履歴は任意の別紙にまとめる。別紙を外しても元の検証状態は変わらない。未読文字列・未確定行を正解として補完しない。本文の文章をAIで新たに作る機能は含まない。

生成した `.tex` はコンパイラー未設定時やエラー時にもダウンロードできる。固定テンプレートを編集してアップロードする機能は含まない。

## 実行制限

- 入力: 500行、APIリクエスト2 MiB、生成TeX 1 MiB。
- 出力: 50ページ、PDF 4 MiB。Vercel Functionsの4.5 MB制限を考慮する。
- コンパイル: 40秒、同時1件。混雑時は429を返す。自動再試行しない。
- Web中継: 45秒、Route Handlerの最大実行時間60秒。
- コンテナ: 非root、ルート領域読取専用、一時領域256 MiB、メモリ2 GiB、CPU 1.5、64 PID。
- TeXのshell escapeとsocketを無効化。子プロセスにAPIキーを渡さない。専用コンテナは外向きネットワークを持たない。
- 作業ディレクトリは毎回分離し、成功・失敗・タイムアウト・キャンセル後に削除する。生のTeXやコンパイルログを応答に含めない。

## 配置

既存Azure VMと `hackerserver.japaneast.cloudapp.azure.com` を使用する。Caddyが80/443で証明書を取得し、HTTPSを終端する。コンパイラーの8001は内部ネットワークだけで待ち受け、ホストにも公開しない。手書きAIの実行先は変更しない。Vercel担当者への接続設定の引継ぎは別途行う。

詳細は [配置手順](../DEVELOPMENT-report-pdf.md) を参照。
